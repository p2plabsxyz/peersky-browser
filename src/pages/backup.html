Create backup

Bundle your tabs, window layout, P2P identities, PeerChat rooms, and IPFS/Hyper repositories into a single .zip file.

Share via P2P

Upload a backup .zip to IPFS/Hypercore and get a CID you can share. Anyone can restore it from the onboarding screen or below.

Note: Since this uses P2P networks, the device that uploaded the backup (or another peer) must remain online for others to download it.

Restore backup

Replace current data with the contents of a backup .zip. Existing IPFS and Hyper repositories are overwritten and Peersky must restart to apply changes.
